# אישורי הגעה לבר המצווה

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/elicohen27-cell/bar-mitzvah-rsvp)

Worker אחד ב-Cloudflare עם מסד D1:
- **דף אישור הגעה אישי** לכל מוזמן בכתובת `/r/<קוד>`. הדף עובד בכל טלפון, בלי חשבון ובלי התקנה. אחרי אישור יש בו כפתורים לוויז, ליומן גוגל וליומן אייפון.
- **לוח בקרה** בכתובת `/admin`, מוגן בסיסמה: סטטוס לכל מוזמן, ספירת אורחים, ייבוא מאקסל, ייצוא לאקסל, סבב תזכורות בוואטסאפ ועריכת נוסחי ההודעות.
- **מסד D1** ששומר את המוזמנים והתשובות. הטבלאות נוצרות לבד בבקשה הראשונה.

## התקנה בלחיצה

1. לוחצים על הכפתור **Deploy to Cloudflare** למעלה ומתחברים ל-Cloudflare.
2. מחברים חשבון GitHub. Cloudflare יוצר בו עותק של הפרויקט.
3. משאירים את כל השדות כמו שהם ולוחצים **Create and deploy**. אחרי כדקה מתקבלת כתובת בסגנון `https://bar-mitzvah-rsvp.<שם>.workers.dev`.
4. פותחים את הכתובת עם `/admin` בסוף. בכניסה הראשונה בוחרים סיסמה ללוח.

מסד הנתונים נוצר אוטומטית, אין צורך ליצור אותו או לחבר אותו.

## בדיקה ראשונה

1. בלוח הבקרה לוחצים **בדיקה מהירה**. נוצר מוזמן לדוגמה, ובהודעה שקופצת יש קישור לדף שלו.
2. עונים בדף כמו מוזמן, וחוזרים ללוח. התשובה מופיעה תוך חצי דקה, או מיד אחרי רענון.
3. בלשונית **פרטי האירוע ונוסחים** ממלאים שם, תאריך, שעה, מקום וכתובת. השמירה אוטומטית.
4. ב-**ייבוא רשימה** מסמנים "למחוק קודם את כל הרשימה הקיימת" ומדביקים את הרשימה האמיתית: שורה לכל הזמנה, `שם, טלפון, קבוצה, מספר מוזמנים`.

## התקנה ידנית (אם הכפתור לא מתאים)

**דרך הדשבורד:** יוצרים Worker מסוג Hello World, מדביקים את התוכן של `worker.js` ב-Edit code ופורסים. אחר כך ב-Settings → Bindings מוסיפים D1 database בשם `DB`.

**דרך Wrangler:**
```bash
npm install
npx wrangler login
npx wrangler deploy      # יוצר את מסד ה-D1 אוטומטית בפריסה הראשונה
```

## סיסמה

- הסיסמה נבחרת בכניסה הראשונה ל-`/admin` ונשמרת במסד כ-hash.
- אם מוסיפים ל-Worker סוד בשם `ADMIN_PASSWORD`, הוא גובר על הסיסמה מהמסד. זו גם הדרך לאפס סיסמה שנשכחה.
- החלפת הסיסמה מנתקת את כל מי שמחובר ללוח.

## כמה דברים שכדאי לדעת

- **הלינקים האישיים** מורכבים מ-7 תווים אקראיים, ולכן אי אפשר לנחש אותם. מי שיש לו לינק רואה רק את ההזמנה של עצמו.
- **ההערה** בכרטיס של מוזמן גלויה לו בדף שלו. הערות פנימיות כדאי לכתוב במקום אחר.
- **מחיקת מוזמן** או ייבוא עם "למחוק קודם" מבטלים את הלינקים הישנים.
- **כתובת יפה יותר:** אם יש לך דומיין ב-Cloudflare, אפשר לחבר אותו ב-Settings → Domains & Routes. הלינקים בהודעות מתעדכנים לבד לכתובת שממנה פתחת את הלוח.
- **הקוד המקורי** (לוח הבקרה והשרת בנפרד) נמצא אצל Claude. `worker.js` הוא הגרסה המאוחדת שלו.
